# 3W Social App

A full-stack social media web application where users can register, log in securely, create posts, like/unlike posts, add comments, and view their profile.

## Features

- User Signup
- User Login
- JWT Authentication
- User Profile
- Create Posts
- View Social Feed
- Like / Unlike Posts
- Add Comments
- Logout
- MongoDB Database
- Basic Responsive UI

## Tech Stack

### Frontend
- React.js
- Vite
- Axios
- CSS

### Backend
- Node.js
- Express.js
- JWT
- bcrypt
- MongoDB
- Mongoose
